## 35年全史统计结论 (已验证, 勿重算)
- 暴跌日 (等权<-2.5%) 次日: n=338 均值 +0.88% / 56% 涨; 连续暴跌后 +2.70%/60%
- 恐慌暴跌 (<-4%) 次日不反弹 (+0.16%) — 恐慌有惯性
- 反弹结构: 创业板领涨 (+1.59%) > 科创 > 沪主板; 高位强势票 +1.59% vs 低位票 +0.68% — 抢超跌强势股不抄低位冷门; 低位票胜率仅 33.5% (均值靠少数暴涨拉平)
- 日历: 周二 +0.110% / 周五 -0.015%; 2月 +0.203% / 1月 -0.079%

## 新引擎验证模式
分片训练 (如 4×800 票) IS70/OOS30 → 各分片 OOS 分位单调才有效 → 权重按 spread 定 → 登记注册表 + 记录去重决策
- ML 推理特征坑: 训练特征列名与推理输入必须同名同源 — 推理用简化特征集时缺失列被中位数填充, 输出全体同分, 表面跑通实则无效; 验证方法是看输出分布是否退化。推理前先查最新截面 NaN 占比: 因子增量脚本只写自己算的列, 其余列在最新日期全 NaN → 同样全体同分; 解法 alphas/factor_full_daily.py 从 qfq_all 重算 30 个量价因子补齐 (幂等 delete+insert, 注意 factors_wide 主键列名是 symbol 不是 sym, rename 后再 INSERT)
- 二分类阈值按目标定制: 用户要「明日强涨」就把标签改成 fwd_ret>3% 加 scale_pos_weight 平衡, 比通用「明日涨跌」AUC 和 TOP 精度都高一档

## 去重决策存档 (吸收上游前先查这里)
- NB+GBDT 同源 → 合并 ml_ensemble 单票
- dual_trend 与 factor117 重叠 → 降权 0.8
- CYQ 获利盘是筹码维度非价格位置 → 独立票; 上游 240 日低位与 pos240 重叠 → 不吸收
- calendar 是乘数不独立计票
- 经典指标 (MACD/RSI/KDJ/SuperTrend) 上游 64250 样本校准 edge 全负 — 不收录
- 尾数8 招财证伪; 尾4 +0.46% 是幸存者偏差 — 均不收
- 玄学治理: 过了数据关的 (日历) 入引擎, 没过的直接说没过
- 量价A股铁证 (主板近一年样本): 昨涨>3%+量比2-4 → 次日≥4%概率32%/涨停率8.4% (基准4倍); 量比2-4是甜区, >4爆量反而衰减 (太晚); 光放量不涨是陷阱 (涨停率仅1.9%)
- 涨停题材前兆: 涨停潮常在结构性题材里 (指数跌+涨停潮并存=抱团结构市), 板块级「多票同日集体放量(量比>3)」是次日涨停潮前兆, 与指数涨跌无关; 纯量价抓不到的平盘放量型涨停需题材梯队叠加
- 三连阴冰点后首反弹日 (n=15): +1日胜率73%, +3日分歧掉到47%, 5日累计80%胜率中位+1.79% — 反弹前两日可积极参与, 第三日起看量, 缩量滞涨=反弹结束
- 买入区间 (A组信号票次日行为 n=5956): 89%会回踩昨收下方 (中位最低-2.4%), 高开>3%仅8% — 挂单区间=昨收×(0.985~1.00), 高开>2%不追等回踩, 不回踩则放弃
- 完整个股报告模板 (用户定的最低标准, stock_report.py 六层): 大盘层面(三大指数+成交额+放量变化+上涨家数+情绪) → 技术层面(EMA5/10/20 具体数值+排列+乖离+RSI+BOLL位置) → 资金层面(当日+近6日连续流向) → K线形态(近3日+20日高低) → 综合评分 → 决策(买入区间/4%限价/止损/观察条件) — 每层都要具体数字, 空话(如「关注支撑位」)不可接受
