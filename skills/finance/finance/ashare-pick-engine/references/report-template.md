# 六层完整推股报告模板（stock_report.py 已落地实现）

用户定的推股最低完整度标准，每次推票每层都必须有具体数字，不允许定性空话：

1. **大盘层面**：三大指数方向+成交额+较昨日放量变化+上涨家数+情绪温度；个股今日涨幅 vs 上证（强于/弱于大盘）
2. **技术层面**：EMA5/EMA10/EMA20 具体数值+排列判定（多头/空头/纠缠）；乖离率；RSI14；BOLL 中轨/上下轨+现价位置
3. **资金层面**：当日主力净流（腾讯 ff_ 接口）+ 近 6 日净流序列+连续 N 日方向（新浪 MoneyFlow.ssl_qsfx_lscjfb，带 Referer）
4. **K线形态**：近 3 日形态（放量阳线/长下影等）+20 日高低位
5. **综合评分**：tech_score（多头加分/RSI 超买卖分/乖离过大压分）+量比
6. **决策量化**：买入区间=昨收×(0.985~1.00)（历史 89% 信号票次日回踩）；4% 限价=今收×1.04；止损 -3%；观察条件自动化（如「RSI 回落 70 下方且缩量回踩不破 EMA10」）

实现：`/home/agentuser/stockdb/t1/alphas/stock_report.py`（推送于 stocks-algo/alphas/）。用法：`/tmp/senv/bin/python stock_report.py sh600519 [sym2 ...]`。

范例校验：用户给的药明康德样例（空头排列+主力连续 3 日净流出 → 观望）与本模板输出规则一致。
